# 对比物料：模糊回答 vs 可验证读数

> **用法**：发技术群 / 朋友圈配图时直接用「三个问题」这一段。
>
> **诚实声明（重要，别删）**：左栏「凭感觉」是这类问题**常见的模糊回答形态**，用于
> 说明问题所在，**不是对某个具体模型的实测**；右栏全部是麦当劳 MCP **真实接口返回**，
> 数据可复现（仓库内附真实门店快照，不联网也能跑出同样结果）。

---

## 同一个问题，两种回答

### 问题 1

> 我想吃 **550–800 大卡**、蛋白质**至少 30 g**，预算**不超过 40 元**，怎么点？

| | 凭感觉 | 麦麦算盘 |
| --- | --- | --- |
| 回答 | 「随便点两样吧，差不多就行」 | **¥23.80 / 656 kcal / 蛋白 42.0 g** |
| 具体是什么 | 说不出来 | 蘸酱麦麦脆汁鸡 ¥11.90 + 蘸酱炸鸡 ¥11.90 |
| 怎么验证 | 无法验证 | `calculate-price` 真实算价 **¥23.80**，与预测**逐分吻合** |
| 换个问法 | 结果就变了 | 同输入必得同输出（有单元测试） |

### 问题 2

> 「麦辣鸡腿汉堡三件套」到底多少卡、多少蛋白？

| | 凭感觉 | 麦麦算盘 |
| --- | --- | --- |
| 回答 | 「八百多到九百大卡吧」 | **921 kcal / 蛋白 28.0 g / ¥33.50**（原价 ¥46.00） |
| 热量怎么来的 | 估 | 拆成组成逐项求和：麦辣鸡腿汉堡 + 中薯条 + 可乐中杯 |
| 为什么拆 | —— | 因为**营养库只收单品，套餐本身没有营养数据**。不拆就只能猜 |

### 问题 3

> 预算 50 元，想吃到**最多蛋白质**，怎么组合？

| | 凭感觉 | 麦麦算盘 |
| --- | --- | --- |
| 回答 | 「多点鸡胸类」 | **¥38.80 / 984 kcal / 蛋白 63.0 g** |
| 组合 | 说不准 | 蘸酱麦麦脆汁鸡 + 蘸酱炸鸡 + 麦麦脆汁鸡 1 块 |
| 有多确定 | —— | 动态规划在全部可行组合里**取到的最优解**，不是抽样推荐 |

---

## 一句话差别

**不是「AI 帮你挑一个」，是「在一个可验证的约束优化问题里求出最优解」。**

- 数据来源 = 真实接口（营养库 / 门店菜单 / 券池 / 算价），不是模型记忆；
- 决策方式 = 双约束动态规划，不是提示词让模型"挑"；
- 报价 = `calculate-price` 下单前强制复算，不是菜单牌价；
- 数据缺口 = **排除出解**并如实标注，不是按 0 计算伪造"达标"。
