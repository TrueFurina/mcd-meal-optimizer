## 一、榜上头部在「做什么方向、怎么宣发」

### 1.1 方向分布（来自 `官方排行榜快照-20261013.md`，115 项）

| 胜出方向 | 代表性项目 | Star | 为什么能跑出来 |

| **省钱 / 券 / 预算** | mcd-coupon-strategist 232、mcd-budget-meal 142、mcd-saver-strategist 49 | 高 | 痛点最普适：人人都想"点得划算"，标题即钩子 |

| **营养 / 健康** | mcd-order-calories 37、mcd-calorie-* 系列 | 中 | 减脂人群刚需，但同质化最严重 |

**关键事实：32/115 个项目是同一条「营养 / 预算 / 热量 / 券 / 优化」赛道。**
功能层面已经卷不动了——你有的别人都有。榜上分差几乎全来自**宣发触达**，不是功能。

### 1.2 头部项目的通用宣发打法（中文开发者社区共性套路）

1. **痛点标题 + emoji**：「用麦当劳 MCP 点餐，我一个月省了 XXX」「减脂期怎么点麦当劳不超标」。
2. **一个可截图的具体数字**：把工具输出直接贴图，数字越具体越可信。
3. **一行命令跑起来**：降低围观者动手门槛，评论区才好接"求链接"。
4. **「参加 XX 大赛，求 Star」CTA**：把投票机制直接写进文案，把读者转成投票人。
5. **渠道矩阵**：掘金 / 知乎（长文沉淀 SEO）、小红书（爆款图）、朋友圈 / 技术群（高转化）、V2EX / Reddit r/MCP（开发者）。
6. **社交 / 猎奇角度优先**：mbti、算命、心情这类"能晒"的天然比纯工具易传播——这是它们能吃下 30~40 星的原因。

### 1.3 我们的卡点

我们的差异化是**「可验证、不瞎编、数据缺口不伪装」**——这恰恰是绝大多数同赛道项目没有的（很多只是套一层 LLM「帮你推荐」）。但「可验证」是**信任钩子**，不是**传播钩子**；它留得住人，但不好"晒"。要把它变成传播力，得翻译成人话："别人用 AI 猜，我用官方接口算，还逐分复核。"
